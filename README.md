# FOMO Confluence Android

Personal-use read-only Android tracker UI for FOMO top-trader confluence.

## V1 included
- Native Android app, minimum Android 8.0 (API 26)
- Simple dark glass-style UI
- Editable min/max market cap, minimum trader count, and confluence window
- Full selectable/copyable contract address
- Open FOMO button
- GitHub Actions APK build

## Important
The bundled signals are explicitly DEMO DATA. No fake live FOMO feed is presented. A verified live FOMO leaderboard/positions data adapter must be connected next.

## Build APK on GitHub
Upload the contents of this project to the repository root (do not upload the enclosing folder as an extra level). GitHub Actions runs automatically after the push. Open Actions > Build Android APK > latest successful run > Artifacts > FOMO-Confluence-debug.

## Security
Never commit wallet seed phrases, private keys, session cookies, API secrets, or .env files.
